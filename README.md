# 默记 · Word Memorizer

一个专注、纯粹的背单词应用。当前版本是可在电脑浏览器中运行的 MVP，支持闪卡学习、间隔复习、本地词库和学习统计。

## 功能

- 单词闪卡与中英文例句
- 四档记忆反馈和自动复习间隔
- 空格及数字键快捷操作
- 添加、搜索和浏览单词
- 本地持久化学习记录
- 学习统计与深色模式

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 技术栈

React、TypeScript、Vite。后续计划添加 Tauri 桌面外壳和 SQLite 数据库。
